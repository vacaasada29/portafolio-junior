  • HTML

    Construyo la base de cada sitio con estructuras limpias, ordenadas y bien pensadas para que todo funcione perfecto.

  • CSS

    Doy vida al diseño con estilos modernos, colores, formas y animaciones que hacen que la web se vea genial.

  • JavaScript

    Le doy interactividad a las páginas, haciendo que todo cobre vida con efectos, botones y movimientos dinámicos.

    Creo interfaces rápidas y organizadas usando componentes que hacen que cada parte del sitio trabaje en armonía.

    Organizo mis estilos con más control y limpieza, creando diseños fáciles de mantener y personalizar.

  • VS Code

    Mi entorno de trabajo diario, cómodo y flexible, donde escribo, pruebo y organizo cada proyecto con fluidez.

  • Git

    Guardo el avance de mis proyectos paso a paso, sin perder nada y siempre con todo bajo control.

  • GitHub
